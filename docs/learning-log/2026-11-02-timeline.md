## 2026-11-02 — Timeline

- **Built:** `Timeline` + `TimelineItem` for invoice histories and activity feeds: `title`, `actor`, `time` / `timeLabel`, `tone`, `marker` (an icon or `<Avatar size="xs" decorative />`), `upcoming` and `size` (on the list, shared through context). Plain HTML, no headless library.
- **Remember: `<ol>` + `<time dateTime>`.** An ordered list because the order means something: screen readers say "list, 4 items" and can jump between items. `<time dateTime="2026-10-14T09:32:00Z">` keeps the exact value for machines while people read "Oct 14, 2026, 5:32 AM".
- **Remember: a date with no time is a day, not a moment.** `new Date('2026-10-14')` is midnight **UTC**, which is still Oct 13 in the Americas. `formatTime` formats date-only values with `timeZone: 'UTC'`, so the day never shifts. Dates with a time are shown in the reader's own zone.
- **Remember: layout that survives right-to-left.** The line under each marker is a flex column (`flex-1` + `border-s`), not an absolutely placed line at `left: 12px`. It stays centred in RTL and grows with the item on its own.
- Docs: https://developer.mozilla.org/en-US/docs/Web/HTML/Element/time
