## 2026-11-02 — Pipeline Map interactive #5: details panel

- **Built:** `PipelineMapDetails`, a non-modal `<aside aria-label="Details">` for the selected facility or pipe. It shows facts (`<dl>`), tanks (with "high" in words), batches, and the pipes in and out (buttons that select them). Actions: Trace flow (an `aria-pressed` toggle), follow a batch, Show on map. Each action appears only when you pass its callback. The map also gets `selectionFollowsFocus`, so arrow keys update the panel. `connectedPipes()` is exported.
- **Remember (the prediction): don't move focus unless the user asked to go somewhere.** Pressing "Trace flow" changes the map, but focus stays on the button (WCAG 3.2.2, On Input): the user sees it, and the map's live region says it. "Show on map" is the exception because moving is the whole point of that button. Checked in Chromium: `activeElement` is still "Trace flow" after Enter.
- **Remember: landmarks are the page's table of contents.** `<aside>` is role `complementary`; give it a name and screen-reader users can jump to "Details" from their landmarks list, the way `<nav>` and `<main>` work. The heading level is a prop (`headingLevel`), because only the page knows its outline.
- **Remember: "selection follows focus" is an ARIA pattern, and it's opt-in.** Tabs usually do it; listboxes and grids usually don't. Turn it on when selecting is cheap and the result shows nearby (a panel). Leave it off when selecting does something heavy (a fetch, a navigation).
- Docs: https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/complementary.html
