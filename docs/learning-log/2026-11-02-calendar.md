## 2026-11-02 — Calendar / RangeCalendar (standalone)

- **Built:** `Calendar` and `RangeCalendar`, calendars that sit on the page (booking sidebars, "pick a delivery day"). ISO values, `min`/`max`, `unavailable(iso)`, `firstDayOfWeek`, `visibleMonths={2}` (range), `size`, `variant` plain/card. The month header and day grid moved to `date-picker/calendar-parts.tsx`, shared with the DatePicker popovers.
- **Remember: disabled vs unavailable.** Days outside `min`/`max` are **disabled**: the arrow keys skip them and you can't focus them. **Unavailable** days (holidays, booked) can be focused, so a screen reader still reads "Saturday, November 7, 2026" plus "dimmed" or "unavailable" (from `aria-disabled`). They just can't be picked.
- **Remember: one set of parts, many wrappers.** DatePicker, DateRangePicker, Calendar and RangeCalendar render the same `MonthHeader` and `DayGrid`. React Aria's components share slot names and contexts, so the same parts work inside each. A style fix in `calendar-parts.tsx` reaches all four.
- **Remember: React Aria hides the weekday row** (`<thead aria-hidden>`), because each day's own name already says the weekday. Tests read it from the DOM, not by role.
- Docs: https://react-spectrum.adobe.com/react-aria/Calendar.html
