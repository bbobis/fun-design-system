- **Remember: `must(x)` instead of `x!`.** `!` only tells TypeScript "trust me". If you're wrong, the test fails later with "cannot read properties of null". `must` throws right away with a clear message, and its return type `NonNullable<T>` narrows like an `if (x == null) throw` would.
- **Remember: a `useMemo` dependency can be "unnecessary" to the linter and still needed.** The DataGrid's `table` object never changes, so `columns` is what tells the memo the columns changed. Removing it would keep showing errors for columns that are gone. Keep it, and silence the rule for that one line with the reason written above it.
- **Remember: delete `eslint-disable` comments that no longer hide anything.** ESLint reports them as "unused directive" warnings. Stale ones hide future real problems on that line.
