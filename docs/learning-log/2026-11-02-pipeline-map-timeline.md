## 2026-11-02 — Pipeline Map interactive #7: time slider

- **Built:** `PipelineSnapshot` (`{ at, network }`) and `PipelineTimeline`, our `Slider` over snapshot indexes, read out as times ("9:00 AM") with "5 snapshots, 6:00 AM to 10:00 AM" as its description. `Slider` gains a general `getValueLabel`. The map keeps a followed batch that isn't in the current snapshot: every pipe fades, and it announces "… isn't in the pipes at this time" / "… is back in the pipes". `DEMO_TIMELINE` has five made-up hours in which B-1041 travels A-B → B-C → C-D and is delivered.
- **Remember (the prediction): data changing is not the user changing their mind.** The follow is the user's intent, so it survives a snapshot where the batch is gone; the map says so instead of quietly dropping it. Step back and it lights up again. Ids (and batch names) staying the same across snapshots is what makes this work for selection and trace too.
- **Remember: React Aria has three layers. When a component can't do something, look one layer down.** Components (`react-aria-components`) are built from hooks (`react-aria`), which are built on state (`react-stately`). The slider only formats numbers. Importing `react-stately` would have meant a new direct dependency, so instead I used the component layer's own **`SliderStateContext`** to reach the state and change how values are worded. That's React Aria's documented "advanced customization" route.
- **Gotcha: identity matters.** My first try provided a *copy* of the state, and React Aria threw "Unknown slider state": it keys internal data by that exact object (a `WeakMap`). Replacing one method on the same object works, because the state is rebuilt on every render.
- **Gotcha: locale.** The default time format follows the viewer ("6:00 AM" in en-US, "06:00" in en-GB). Tests pin `formatTime` so they don't depend on the machine's locale.
- Docs: https://react-spectrum.adobe.com/react-aria/advanced.html#contexts
