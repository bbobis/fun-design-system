## 2026-11-03 — DataGrid column filters (F3)

- **Built:** `meta.filter` (`text` / `number` / `date` / `list`) adds "Filter…" to a column's menu. It opens a panel under the header (React Aria `Popover` + `Dialog`, a `<form>` with Clear / Apply). Active filters show as removable chips (`TagGroup`) with Clear all, a funnel on the header, and "N of M rows" in the footer. Props: `filters` / `onFiltersChange` / `defaultFilters`. List choices come from `meta.options` or the distinct values in the data.
- **Remember: a discriminated union for the filter value.** `{ kind: 'list', values } | { kind: 'number', min?, max? } | …`. `switch (f.kind)` in `matchesFilter`, `describeFilter` and the panel's fields, and TypeScript checks every case. TanStack sees one registered `filterFn: 'dataGrid'` that calls our pure `matchesFilter`, so the rules are tested without a table.
- **Remember (the prediction): focus returns to what was focused when the overlay opened.** The panel opens two animation frames after the menu closes, once React Aria has already put focus back on the ⌄ button. The Dialog remembers that button and returns focus to it on Apply, Clear or Escape. Our `Popover` component brings its own trigger, so this panel uses React Aria's `Popover` with `triggerRef` (anchored to the header) and `isOpen` instead.
- **Bug found and fixed: a header's name came from everything inside it** ("Status Resize Status column"). Screen readers repeat a column header's name for every cell, so headers now have an explicit `aria-label` ("Status" or "Status, filtered"), and a test pins it.
- Docs: https://react-spectrum.adobe.com/react-aria/Popover.html#custom-trigger
