## 2026-11-03 — Gauge with alarm bands

- **Built:** `Gauge` on React Aria `Meter`: a value against LL / L / H / HH limits (ISA-18.2 names). It has striped band zones, tick labels, a setpoint ▾, horizontal or vertical (tanks), `stale` for lost comms, and an out-of-range value that's clamped on screen but read out for real.
- **Remember: color is for the abnormal (ISA-101).** A normal reading is gray. Green everywhere trains the eye to scan a sea of color, and the one amber gauge gets lost. Warning = amber + ▲, alarm = red + ⚠ + the band in words: never color alone.
- **Remember: `role="meter"` vs `progressbar`.** A meter is a measurement in a known range (pressure, disk space); a progress bar is a task moving to done. `aria-valuetext` ("6,420 kPa, high") replaces the number screen readers would read; without it they'd say "80 percent".
- **Remember: a stale value must look stale.** An old "normal" that looks live is worse than no value. Gray it, drop the band color, and say why.
