## 2026-11-02 — Stat / StatGroup

- **Built:** `Stat` (label, `value` + `format`, change from `previous` with `goodWhen`, `period`, `hint`, `sparkline`, `loading`, `size`) and `StatGroup`. Plain HTML: a description list.
- **Remember: `<dl>` for label / value pairs.** `<dt>` is the term ("Revenue"), `<dd>` the value. Screen readers pair them. A group is one `<dl>`; a lone Stat makes its own (React context tells it which).
- **Remember: format at the edge with `Intl.NumberFormat`.** Components take raw numbers (`84210`) and a format (`{ style: 'currency', currency: 'USD' }`). Then "$84,210", "84 210 $US" (fr-CA) and "1.2M" (`notation: 'compact'`) all come from the same value.
- **Remember: say the change in words.** On screen it's "↑ +12.0%" in green. Screen readers get "Up 12.0% vs September" (sr-only), because "+" and colour don't carry. `goodWhen="down"` flips the colours for things where less is better. From a previous value of 0 there's no % change at all (it would be infinite), so none is shown.
- Docs: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat
